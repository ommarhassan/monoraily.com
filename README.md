# MonoGo | مونوريل القاهرة

نموذج أولي لموقع تخطيط رحلات ومحاكاة تذاكر **مونوريل شرق النيل** (الاستاد ← مدينة العدالة، ٢٢ محطة).
React + TypeScript + Vite، والحسابات والتذاكر المحفوظة على Supabase (اختياري).

## التشغيل

```bash
npm install
npm run dev        # تشغيل محلي
npm run build      # فحص الأنواع + بناء النسخة النهائية في dist/
```

الموقع بيشتغل من غير Supabase (التخطيط والخريطة والأسعار والتذاكر التجريبية). علشان تفعّل الحسابات ولوحة الأدمن:

1. أنشئ مشروع على Supabase وشغّل ملف `supabase/schema.sql` في SQL Editor.
2. انسخ `.env.example` إلى `.env` وحط `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY`.

## هيكل الكود

```
src/
  config/brand.ts      اسم المشروع والشعار وبادئات التخزين (غيّر الاسم من هنا)
  data/
    network.ts         المحطات والخط وأماكن التبديل (أضف خط جديد من هنا)
    fares.ts           مناطق الأسعار ونصف التذكرة والاشتراكات
    mapLayout.ts       إحداثيات المحطات على الخريطة
  lib/
    routing.ts         حساب المسار (أقل تبديلات ثم أقل محطات)
    ticketing.ts       إصدار التذكرة والتحقق من البوابة (تجريبي)
    crypto.ts          التوقيع (HMAC) | storage.ts | format.ts
    supabase.ts, db.ts الاتصال بقاعدة البيانات
  auth/                تسجيل الدخول والحسابات
  hooks/usePlanner.ts  حالة مخطط الرحلة
  components/          مكوّنات مشتركة (Sidebar, Topbar, TicketModal, MonorailScene, ...)
  pages/               صفحة لكل شاشة (Home, Map, Stations, Fares, Gate, ...)
  styles/              ملفات CSS مقسّمة، والألوان الأساسية في base.css
  navigation.ts        قائمة الصفحات
```

## إزاي تضيف صفحة جديدة

1. اعمل `src/pages/NewPage.tsx`.
2. أضفها في `src/navigation.ts` (id + اسم + أيقونة).
3. أضف `case` لها في `renderPage()` داخل `src/App.tsx`.

## ملاحظات على البيانات

- أسماء المحطات وترتيبها وأسعار التذاكر والاشتراكات من إعلانات وزارة النقل والهيئة القومية للأنفاق (٢٠٢٦). راجعها قبل التسليم لأنها ممكن تتغير.
- زمن الرحلة تقديري (٣ دقايق لكل محطة، يعني الخط كامل حوالي ٦٣ دقيقة).
- خط غرب النيل معروض كـ "قريبًا" بس، ومش داخل في حساب المسارات.
- التذاكر والبوابة **محاكاة**: التوقيع بيتم في المتصفح، والنظام الحقيقي لازم يوقّع ويتحقق من السيرفر.
